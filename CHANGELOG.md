# Changelog

## 1.0.0 — Initial foundation

- Crimson click GUI with animated open/close transitions and category navigation.
- Right Shift menu key and configurable hold-to-zoom key.
- HUD modules for coordinates, FPS, direction, armor, effects, health, hunger, ping, biome, clocks, attack recharge, sprint status and keystrokes.
- Fullbright preference, theme presets, click sound and save/load/reset configuration.
- Chest and ore scanning restricted to single-player or exact multiplayer hosts explicitly allow-listed by the player with server-owner permission.
- MIT license, mod metadata, icon, README and GitHub Actions workflow.

This is an initial source foundation. A successful Gradle build and in-game test are required before calling it release-verified.
