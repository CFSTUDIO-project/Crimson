# Contributing

- Keep changes compatible with Minecraft Java 1.21.11, Fabric Loader 0.18.x, Fabric API 0.141.x and Java 21.
- Keep the mod client-side unless a separate server component is reviewed.
- Do not add packet manipulation, automated attacks or features that defeat server rules.
- Run `gradle --no-daemon clean build` and test in a disposable 1.21.11 instance before submitting changes.
- Never commit tokens, passwords or private server credentials.
